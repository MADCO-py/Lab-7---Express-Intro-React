# Laboratorio 7 – Express y React

En este laboratorio se desarrollaron dos partes:

* **Parte 1:** Implementación de un servidor utilizando Node.js con Express.
* **Parte 2:** Desarrollo de una calculadora utilizando React.



 Tecnologías 

* Node.js
* Express
* React



## 🔹 Parte 1 – Servidor con Express

Se creó un servidor que maneja rutas GET y POST, permitiendo responder solicitudes y procesar datos en formato JSON.
